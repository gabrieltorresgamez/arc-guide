# CLAUDE.md

Content rules for `content/` (articles are generated by LLM agents from public web sources, then claim-checked):

1. Every statement must be supported by a source listed in the article. Never invent citations or add knowledge from memory.
2. Own words. Do not copy sentences from a source. At most one direct quote per article, at most 25 words, in quotation marks.
3. English (US spelling), plain language for non-architects, no marketing tone. No information about people.
4. Categories, arc42 sections and guide steps come from `taxonomy.yaml`. Never invent new ones.
5. A source must be publicly readable, because the build checks quoted evidence against the real page. A paywalled source may only be listed as further reading, never as support for a statement.
6. Diagrams render only through the local Kroki (`KROKI_URL`, default `http://localhost:8000`), never a public renderer.
7. Never commit or push; the user does.

Build: `docker compose up -d`, then `uv run python -m pipeline.build`. Tests: `uv run pytest`.
